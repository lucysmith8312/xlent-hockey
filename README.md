# XLENT 冰球礼物工坊

独立静态网站：三款原创布局、冰鞋和球杆开关、自定义名字/队伍/号码/年份、四种颜色、挂孔、尺寸、底板及浮雕厚度。支持中英文，名字最多14字、队伍最多22字。数字使用 Anton，文字使用 Noto Sans CJK。

## GitHub 上传
1. 解压 XLENT-Hockey-GitHub-Upload.zip。
2. 推荐新建仓库 xlent-hockey。上传解压后所有文件及 fonts 文件夹，让 index.html 直接位于仓库根目录；不要只上传 ZIP。
3. 启用 GitHub Pages，从包含这些文件的分支根目录发布。
4. 部署后用网站链接打开。不要直接双击本地 index.html，浏览器会阻止模块或字体读取。
所有资源随包提供，不依赖远程字体或 CDN。无需账号、密钥、服务器或付费 API。

## 使用
选择布局，填写信息和颜色，点击“生成我的冰球礼物”。拖动可旋转，支持正面/背面视角。
彩色3MF包含同一个对象的多个颜色部件。导入切片软件后保持组装位置，核对并分配耗材。STL为合并单色实体。SVG/PNG为实际轮廓的正面效果图。
保存方案为JSON，可在网站“打开方案”继续编辑。不是模型文件。
默认图案高度115mm。默认2.4mm底板+0.8mm浮雕，总厚3.2mm。图案高度不含顶部挂孔，最终外形尺寸在网页显示。孔径不随图案整体缩放。
关闭挂孔为平背装饰牌；此版未设磁铁槽。开启球杆时为交叉双杆，冰鞋为成对的简化冰球鞋。

## 打印
平背朝下。所有浮雕都由底板承托，导出模型位于Z=0。
文件不包含机器、支撑、层高等切片预设。长名字/队名会自动缩小，小尺寸需检查笔画可打印性。
已验证三款×四种装饰组合、整体连通、颜色体积不重叠、STL及3MF结构、中文和尺寸边界。尚未完成真实浏览器端到端测试或实物试打印，不保证所有切片器自动正确分配耗材。

## 开发
安装Node.js后运行 npm ci、npm run build；npm run dev 启动本地静态服务。
npm test 运行几何和导出检查，并更新 examples 中的三款样例。
src/model.js 定义造型；src/app.js 定义交互；src/export.js 定义导出；dist/index.html、style.css 为页面。
dist 是可部署版本；修改源代码后需重新构建。
